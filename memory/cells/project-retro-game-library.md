Project 'retro game library' (org/projects/retro-game-library.md, status active, owner brad, no repo). Brad wants one place to browse/launch a retro collection with good metadata; Pegasus is ruled out (no stable release since weekly_2024w38, site can't report its own latest version, metadata is user-maintained) and LaunchBox is ruled out (closed source, Big Box is a paid unlock, features gated by lock mode per its changelog).

card-017 done 2026-10-30: org/notes/retro-game-library-options.md holds 12 live candidates in four models - desktop launcher (Playnite MIT, SimpleLauncher GPL-3, ES-DE 3.5.0, OpenBoxGL AGPL-3), self-hosted library server + clients (RomM AGPL-3 14,160 stars - can import LaunchBox metadata, has Playnite/Android/CFW clients; Gaseous AGPL-3), import-into-Steam (steam-rom-manager GPL-3), build-our-own.

Open: Brad's call on target device, desktop-vs-server, metadata source, and whether to build our own. Nothing installed; no install without asking.
