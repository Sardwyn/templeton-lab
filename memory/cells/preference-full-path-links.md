Brad reads paths, not ids: every card, note, decision, build, memory cell or event reference shown to him must be a clickable link labelled with its full F:\Lab\... path, opening the file itself (serve.py /raw/<rel>, or ../<rel> when the dashboard is opened from disk). Never show a bare id as the only reference, never fabricate a path for a file that does not exist - show it dim instead.
